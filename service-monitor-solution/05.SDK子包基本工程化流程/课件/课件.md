在根目录下创建好ts相关配置之后，子项目中的内容可以直接继承根目录下面的配置即可

比如packages/browser，可以创建自己的tsconfig.json文件

```json
{
  "extends": "../../tsconfig.json",
  "include": ["src/**/*"],
  "compilerOptions": {
    "types": ["node"],
    "lib": ["DOM", "ESNext"],
  }
}
```

整个项目需要进行编译打包，由于都是基于TS的项目，我们这里基于[tsup](https://www.npmjs.com/package/tsup)工具进行处理，在根目录下安装tsup

```shell
pnpm add tsup -D --workspace-root
```

然后我们就可以在browser项目中创建tsup.config.ts配置文件

```typescript
import { defineConfig } from "tsup";

export default defineConfig([
  {
    entry: ["src"],
    format: ["cjs"],
    outDir: "build/cjs"
  },
  {
    entry: ["src"],
    format: ["esm"],
    outDir: "build/esm"
  },
  {
    entry: ["src"],
    format: ["iife"],
    outDir: "build/umd",
    name: "duyi-monitor-sdk-browser"
  }
]);
```

这样，我们先在browser的src的index.ts中完成init方法，具体的代码先不关注，我们先搭建框架

```typescript
export const init = (options: unknown) => {
  console.log("init", options);
};

```

注意，这里如果使用any，会报出eslint错误：`@typescript-eslint/no-explicit-any`，如果希望使用any，可以在eslint规则中，关掉这个规则：

```typescript
rules: {
  ......
  "@typescript-eslint/no-explicit-any": "off",
}
```



#### 6.接下来关注点，子包的内容如果被其他项目所引用？

实现SDK开发需要关注：

1.产物如何构建

2.产物构建的内容如何被其他子包使用，当然要使用要非构建方式，要么构建方式，当然我们既然都分包了，当然使用构建的方式进行引用是比较好的。

因此，在package.json中，需要定义相关的`tsup`构建脚本

```typescript
"scripts": {
  "build:watch": "pnpm run build:watch:transpile & pnpm run build:watch:types",
  "build:watch:transpile": "tsup --watch",
  "build:watch:types": "tsc -p tsconfig.types.json --watch",
  "build": "pnpm run build:transpile & pnpm run build:types",
  "build:transpile": "tsup",
  "build:types": "tsc -p tsconfig.types.json"
},
```

ts类型相关的配置

```json
{
  "extends":"./tsconfig.json",
  "compilerOptions": {
    "declaration": true,
    "declarationMap": true,
    "emitDeclarationOnly": true,
    "outDir": "build/types",
  }
}
```

运行`pnpm run build:watch`就能看到生成的各种文件，一些优秀的开源项目，产物构建基本都是这种形式的

#### 7.产物构建好之后，需要在package.json中进行相关配置，外部才好使用

需要对`package.json`文件进行工程化相关配置

```typescript
"main": "build/cjs/index.js",
"module": "build/esm/index.mjs",
"types": "build/types/index.d.ts",
"exports":{
  "./package.json": "./package.json",
  ".": {
    "import": {
      "types":"./build/types/index.d.ts",
      "default":"./build/esm/index.mjs"
    },
    "require": {
      "types":"./build/types/index.d.ts",
      "default":"./build/cjs/index.js"
    }
  }
},
```

#### 8.在vanilla项目中进行引用

pnpm monorepo项目可以直接进行引用设置，在`package.json`文件中，直接设置`dependencies`属性即可

```typescript
"dependencies": {
  "@duyi/monitor-sdk-browser": "workspace:*"
},
```

这样定义好之后，直接执行`pnpm i`即可引入

当然，你也可以通过命令进行引入：

```typescript
pnpm add @duyi/monitor-sdk-browser --workspace --filter vanilla
```

这样，才main.ts中就可以引入init方法了

```typescript
import { init } from "@duyi/monitor-sdk-browser";

init({
  dsn: "http://localhost:8000/appid-xxx"
});
```

当然，现在就可以运行这个测试项目了`pnpm run dev`

而且，子包的browser我们是可以watch启动的，这样不用每次都进行编译才能看到效果，在browser中，运行`pnpm run build:watch`，这样每次更改之后就能直接看到效果
